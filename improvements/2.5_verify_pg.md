# Verifying PostgreSQL Cluster Status
This document provides information to verify the PostgreSQL Cluster status after installation.


## Check PostgreSQL cluster object and pods
1. Monitor the cluster creation progress:
```bash
kubectl get pg -n postgres-operator
```
The cluster status will show `ready` when all components are running. You should see output similar to:
```bash
NAME       ENDPOINT                                   STATUS   POSTGRES   PGBOUNCER   AGE
cluster1   cluster1-pgbouncer.postgres-operator.svc   ready    3          3           5m
```

2. Check the Pods and ensure that all the pods are in `Running` state and there are no container restarts of late. 

```bash
% kubectl get po -l app.kubernetes.io/instance=cluster1,app.kubernetes.io/managed-by=percona-postgresql-operator
```
Output will be similar to this
```
NAME                                  READY   STATUS      RESTARTS   AGE
cluster1-backup-l962-rjrnb            0/1     Completed   0          21h
cluster1-instance1-29rs-0             4/4     Running     0          21h
cluster1-instance1-c9qt-0             4/4     Running     0          21h
cluster1-instance1-g9ml-0             4/4     Running     0          21h
cluster1-pgbouncer-775cd78f4d-lst4k   2/2     Running     0          21h
cluster1-pgbouncer-775cd78f4d-w8jdl   2/2     Running     0          21h
cluster1-pgbouncer-775cd78f4d-w94qt   2/2     Running     0          21h
cluster1-repo-host-0                  2/2     Running     0          21h
```
